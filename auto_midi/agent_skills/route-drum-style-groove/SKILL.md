# Route Drum Style and Groove

Read the complete song plan before routing. Treat `style` as the song-level
drummer/DNA family and `groove` as the recognizable rhythmic skeleton.

## Routing order

1. Preserve a locked UI style.
2. If style is free, choose one concrete style from whole-song evidence.
3. Preserve a locked UI groove and assign it to every section.
4. If groove is free, choose one concrete global groove inside the routed style.
5. Assign the global groove to every section first.
6. Add a section override only for explicit skeleton-level evidence such as
   half-time, double-time, shuffle-versus-straight, one-drop, motorik, or a
   deliberately patternless release.

Do not switch grooves merely because a chorus is louder, a verse is quieter,
or a section needs a fill, cymbal change, buildup, dropout, or density change.
Express those differences through intensity, density, curves, fills, cymbal
roles, and voice controls.

## Stability rules

- Prefer one groove for the whole song.
- Two grooves require clear structural evidence.
- More than two grooves require an exceptional, explicit arrangement brief.
- Repeated sections and parallel verses inherit the same groove unless the
  brief explicitly changes their rhythmic identity.
- Never output `free` as a final style or groove.
- Every groove must belong to the routed style.
- Give concise routing reasons based on rhythm, not lyrical mood alone.

The application appends the current live catalog and routing constraints below
these instructions. Treat that appended catalog as authoritative.
