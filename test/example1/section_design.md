# Example 1：段落设计表

## 全局信息

| 字段 | 内容 |
|---|---|
| 歌曲结构 | Intro → Verse 1 → Chorus → Outro |
| 总长度 | 56 小节 |
| 全局拍号 | 未指定，暂继承程序默认值 |
| BPM | 未指定 |
| 整体情绪 | 叙事、疏离、怀旧、压抑但不爆发 |
| 整体鼓手风格 | 松弛律动型 |
| 鼓组总体策略 | 前段克制，中段展开，结尾逐渐抽空 |
| 重拍/歌词落拍 | 暂不处理 |

## 段落配置

### Intro

```text
段落类型：Intro
小节数：8
拍号：继承全局
强度：10 → 25
情绪方向：悬浮、等待
鼓手风格：松弛律动型
鼓组完整度：无 → 部分
节奏密度：低
Kick：可不出现，或后半段少量出现
Snare/Clap：不主动建立完整 backbeat
Hi-hat：低密度、稀疏
Fill：无
段落结尾：轻微提示 Verse 进入
```

### Verse 1

```text
段落类型：Verse
段落编号：1
小节数：16
拍号：继承全局
强度：25 → 35
情绪方向：叙事、克制、隐约害怕
鼓手风格：松弛律动型
鼓组完整度：部分
节奏密度：低 → 中低
Kick：低活跃度
Snare/Clap：明确但不突出
Hi-hat：低至中等密度
Ghost Note：少量
Fill：少
重复变化：后 8 小节略增加
段落结尾：最后 1～2 小节稍微增加推进
```

### Chorus

```text
段落类型：Chorus
段落编号：1
小节数：16
拍号：继承全局
强度：50 → 65
情绪方向：阴郁、凝聚、开放但不爆发
鼓手风格：松弛律动型
鼓组完整度：完整
节奏密度：中
Kick：中等活跃度
Snare/Clap：稳定、明确
Hi-hat：中等密度
Ghost Note：中低
Fill：每 8 小节一次，段尾略明显
Crash/Ride：适度使用
重复变化：后 8 小节增加少量层次
段落结尾：不做强烈终止，为 Outro 留出回落空间
```

### Outro

```text
段落类型：Outro
小节数：16
拍号：继承全局
强度：45 → 10
情绪方向：怀旧、停留、逐渐远去
鼓手风格：松弛律动型
鼓组完整度：完整 → 无
节奏密度：中 → 低
Kick：前 8 小节保持，后 8 小节逐步减少
Snare/Clap：逐步弱化
Hi-hat：逐步稀疏
Ghost Note：少量
Fill：不增加，避免破坏收束感
Dropout：后 4～8 小节明显增加
结尾：保留空间，不强行制造结束感
```
